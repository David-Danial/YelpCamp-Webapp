# YelpCamp-Webapp
A full-stack MERN web application for exploring, reviewing, and managing campgrounds with authentication, maps, image uploads, and real-time features.

🏕️ YelpCamp
  YelpCamp is a full-stack MERN web application inspired by Yelp, designed for campers to explore, review, and manage campgrounds. It demonstrates end-to-end web development skills including authentication, secure backend APIs, responsive UI, database management, and deployment.

✨ Features
  🔑 Authentication & Authorization – Secure login, signup, and role-based access (User/Admin).
  🏕 Campground Management – Add, update, and delete campgrounds with images and descriptions.
  ⭐ Reviews & Ratings – Users can leave reviews and star ratings for campgrounds.
  📍 Interactive Maps – Location-based campground search using Mapbox/Leaflet.
  🖼 Image Uploads – Multiple image uploads with cloud storage integration (Cloudinary).
  🔒 Security – Password hashing, input validation, and protection against common web vulnerabilities.
  📊 Dashboard (Optional Upgrade) – Analytics for number of users, reviews, and camps.
  🚀 Deployment Ready – Hosted on cloud with MongoDB Atlas, CI/CD enabled.


🛠 Tech Stack
  Frontend: React (or EJS if you kept it) + TailwindCSS/Bootstrap
  Backend: Node.js, Express.js
  Database: MongoDB (Atlas)
  Authentication: Passport.js / JWT
  Maps: Mapbox / Leaflet
  Deployment: Vercel / Render / Heroku / Docker


🚀 How to Run Locally
  git clone https://github.com/your-username/yelpcamp.git
  cd yelpcamp
  npm install
  npm run dev
